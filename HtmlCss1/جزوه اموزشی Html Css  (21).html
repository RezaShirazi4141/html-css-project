۲. شبه‌عنصرها (::first-letter و ::first-line)

برنامه‌نویسی و طراحی وب استانداردهایی دارد که رعایت آن‌ها کیفیت کار را بالا می‌برد. با استفاده از شبه‌عنصرها می‌توان بدون افزودن تگ اضافه به HTML، حرف اول یا خط اول یک پاراگراف را استایل‌دهی کرد تا ظاهر مقالات مانند مجلات معتبر شود.
